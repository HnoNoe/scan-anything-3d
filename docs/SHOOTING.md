# 拍摄规范（决定成败）

同样的工具，拍得好不好结果是天壤之别。这一页把"能建成"和"建得漂亮"的区别讲清楚。

## 黄金五条

1. **环绕一整圈，别停下来**。20–30 秒连续视频，移动慢而匀速（每圈 15–25 秒）。
   后续按 2.5 fps 抽帧可得 50–80 张，视角均匀、相邻重叠大——这是视频比零散照片
   稳得多的根本原因。
2. **目标占画面 1/3 以上**。越远细节越少；想要细节，凑近，让目标占画面一半以上。
3. **物体绝对不能动**。手持相机可以晃一点，但物体本身一个像素都不能动。
   会动的物体（宠物、窗帘、风吹的植物）是失败主因。
4. **均匀光照**。自然散射光最好；避免逆光剪影、频闪灯光、移动的影子。
5. **避开天敌材质**：纯透明（玻璃）、强反光（镜面/亮漆）、大面积纯色无纹理表面。
   混合材质（比如亮漆桌面上的茶杯）通常仍能建成，只是对应区域缺点。

## 进阶技巧

- **两个高度**：环绕一圈后，可以从略高/略低的角度再补半圈，顶部细节会更好。
- **背景有纹理更好**：纯色白墙不是不行，但带点纹理（书架、桌面）帮相机定位更稳。
- **要真实尺寸**：在画面里放一把尺子或已知边长的标定物，拍进去，重建后用它做
  尺度归一，否则点云只有相对比例。
- **大物体**（家具、房间）：放慢到每圈 40–60 秒，步子更密。
- **小物体**（<10 cm）：用手机最近对焦距离，最好垫一张纹理丰富的纸当背景。

## 常见问题自查

| 症状 | 原因 | 对策 |
|------|------|------|
| `SfM 失败：没有生成 sparse/0` | 视野重叠不够 / 物体动了 / 太光滑 | 重拍：更慢、更近、光照更均匀 |
| 注册帧数远低于抽帧数 | 部分段落模糊或重叠不足 | 看视频里哪段糊，重拍那一段 |
| 点云有大洞 | 该角度没拍到，或表面反光/透明 | 补拍那个角度 |
| 物体变形、重影 | 物体在拍摄中动了 | 固定物体重拍 |
| 尺寸不对 | 单目重建只有相对尺度 | 放尺子做尺度归一 |

## 重建后

- `fused.ply` 用 [Meshlab](https://www.meshlab.net/) 或
  [CloudCompare](https://www.cloudcompare.org/) 打开查看；
- 想要实体模型（3D 打印、渲染），在 Meshlab 里做 Poisson 表面重建；
- 只想快速看一眼，用本仓库的 `view_ply.py` 出俯/侧视图。
